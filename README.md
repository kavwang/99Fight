# 99 Fight 乘法記憶遊戲

一個透過九九乘法表練習的簡易小遊戲：

## 規則簡述
1. 上方顯示玩家與怪獸的血量。怪獸會每隔一段時間自動攻擊玩家。
2. 下方是 m x n 的數字方格。數字來源自 2..9 的乘法 (a, b, a*b)。不會出現 1。
3. 玩家點擊格子選取 3 個相鄰的格子。如果這三個數字可組成 `a x b = c` (順序不限)，即視為成功：
   - 造成對怪獸的傷害 (依 a*b 與 combo 加成計算)。
   - 被消除的格子會補上新數字。
4. 被怪獸打到 combo 會歸 0。玩家若將怪獸血量降為 0 則勝利；玩家血量歸 0 則失敗。
5. 重新開始可調整盤面大小、初始血量與怪物攻擊間隔。

## 操作說明
- 設定列數、行數 (4~10)。
- 設定怪獸攻擊間隔秒數。
- 設定玩家與怪獸初始 HP。
- 按「開始」進入遊戲。點擊 3 個相鄰格子嘗試組成乘法算式。
- 若選錯會自動解除；選對會對怪獸造成傷害並補上新數字。

## 技術重點
- 單檔 `index.html`，使用原生 HTML/CSS/JS。無外部依賴。
- 利用 BFS 檢查三格是否連通 (相鄰)；暴力排列驗證是否乘法關係。
- 遊戲狀態集中在 `state` 物件。事件綁定在開始時建立。
